# Exercise 13: Lists & ArrayList

## Task 13.1

Write a program that will define a list of type `string`, and will define another list of type `int` in which the members will be the lengths of the strings from the first array. The program must work properly for arbitrary number of list members. Prompt the user to enter list elements until they enter a number. Print the lists.

## Task 13.2

Write a program that will declare a list of type `int`. Ask the user for input list elements until the user types a letter. Define and print a list of type `double` in which the members will be half the value from the first list.

## Task 13.3

Write a program that will define 2 lists of type `double`, and will also define a third list of type `double` in which the members will be all the members from the first two lists. The program must work properly for arbitrary number of list members. Prompt the user to enter list elements until they type a letter. Print the lists.

## Task 13.4

Write a program that will define a list that will contain the first `n` two-digit numbers. Ask the user to enter the number `n`, and force him not to enter a number greater than the maximum number of two-digit numbers. Print the list.

## Task 13.5

Write a program that, for a defined list of type `int`, will check if there are at least two of the same members in the list. Ask the user to enter the elements of the list until they enter a real number. Print the list and repeating members.
