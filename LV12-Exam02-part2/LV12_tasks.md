# Exercise 12: Exam 02 (Part 2)

## Task 12.1

Write a program in C# that prints the number of seconds until the nearest new year (which has passed or which is coming next) for the entered date from the keyboard.

## Task 12.2

Write a program in C# that removes all spaces from the typed text from the keyboard.

## Task 12.3

Write a program in C# that creates a series of strings `string[]` from the typed text from the keyboard so that each word from the text becomes a new string in the sequence.

## Task 12.4

Write a program in C# that, for a date entered from the keyboard, prints the dates of all Tuesdays of the month.
