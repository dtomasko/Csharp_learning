# Exercise 8: 2D Arrays

## Task 8.1

Initialize a 2D array of size 3x5 (3 rows, 5 columns) with integers, and print what percentage of numbers in each row is smaller than the average of the entire 2D array.

## Task 8.2

Initialize an integer 2D array of size 3x5, load the first two rows from the keyboard. The third row consists of numbers that are the sum of each individual column above it.
**Example:**

```text
3, 6, 1, -9, 3
1, 0, -2, 4, 2
4, 6, -1, -5, 5
```

## Task 8.3

Write a program that will store the multiplication table in a two-dimensional field (use column and row multiplication). Print tabular.

## Task 8.4

Load your name and create a field that has as many columns as the name has letters and ten rows. Store the letters of your name in the first row, and the following rows contain letters that continue alphabetically. Print that field tabularly.

> Use the English alphabet and after "z" comes "a".

**EXAMPLE:**

```text
I v a n
j w b o
k x c p
l y d q
m z e r
n a f s
o b g t
p c h u
q d i v
r e j w
```

## Task 8.5

Load a four-digit number and create a 2D array with 4 rows and 4 columns. The digits of the number go in order in the first row, and each subsequent row contains three times larger numbers than in the previous row. Print that tabular field.

**EXAMPLE:**
Number `3567` has been loaded.

```text
3 5 6 7
9 15 18 21
27 45 54 63
```
