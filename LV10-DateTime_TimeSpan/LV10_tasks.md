# Exercise 10: DateTime & TimeSpan

## Task 10.1

Write a program that loads the date of birth, and prints the day, month and year separately. Also write the date of the 18th birthday.

## Task 10.2

Write a program that loads the date of birth, and prints how old the person is, but in days and months. (It does not use the `TimeSpan` structure.)

## Task 10.3

Write a program that enters the working time (h:m:s) of the person on the project for each day, the project lasted 3 days. The total working time should be printed in hours, minutes and seconds (h:m:s). Use a loop and the `TimeSpan` structure.

## Task 10.4

Write a program similar to task 10.3, but print the average working time per day.

## Task 10.5

Write a program in C# that determines whether the entered year is a leap year.

## Task 10.6

Write a program in C# to display various time data:

- Current date and time
- Current year
- Month of the year
- Number of weeks in the year
- Day of the week
- Day of the year
- Day of the month
- Name of the day of the week
  Apply the appropriate methods and properties if they exist.

## Task 10.7

Write a program in C# that will calculate your current number of days of life after entering the date of birth. It uses methods of the `DateTime` and `TimeSpan` classes. Write the days of your life.

## Task 10.8

Write a program in C# that prints the date of the fifth Tuesday of the month, if it exists. Entry of the month and the year is from the keyboard.
