# Note

Up until **LV 9** we weren't allowed to use class string. Most exercises include `Console.WriteLine` outputs and comments in **Croatian**.

## General Information

- **Execution**: To run a task, copy the code from the corresponding `.cs` file into your IDE
  or simply install dotnet sdk on your pc and clone the repo and run it in a code editor.
- **Structure**: Each level folder contains a set of tasks and their implementations.
